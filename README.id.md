## Mengapa RyanDPI?

- **Bukan VPN Jarak Jauh — Kecepatan Penuh ISP & 0 ms Lag Game:** Trafik Anda tetap langsung melalui Wi-Fi/IndiHome/Biznet/Telkomsel/XL Anda sendiri tanpa lewat server luar negeri. Ping game online (Valorant, Mobile Legends, Roblox, CS2) tetap 100% normal!
- **DNS Terenkripsi Bawaan (Anti Pemblokiran DNS):** Menggunakan **DNSCrypt-Proxy** di Windows dan **Gateway DoH HTTP/2** (`1.1.1.1` / `8.8.8.8` / `9.9.9.9`) di Android untuk melewati pemblokiran DNS ISP secara otomatis.
- **Mesin DPI 7-Tahap Global Universal:** Otomatis melewati pemblokiran SNI/DPI di Indonesia, Turki, Rusia, serta mode khusus **Split-Tunnel Discord Brasil**.
- **8 Bahasa Bawaan (1 Klik):** Termasuk **Bahasa Indonesia (`ID`)**, Inggris, Turki, Portugis Brasil, Rusia, Persia, Mandarin, dan Arab di Windows maupun Android.
- **Pembaruan Otomatis SHA-256 & Uji Akses Langsung:** Verifikasi situs yang terbuka dan ping secara real-time langsung di dalam aplikasi.

## Cara Menggunakan

### Windows (10 & 11 x64)
1. Unduh dan jalankan **[RyanDPI-Setup-Windows-3.0.0.exe](https://github.com/CallMeRyanYT/RyanDPI/releases/download/v3.0.0/RyanDPI-Setup-Windows-3.0.0.exe)** (atau ekstrak [Portable ZIP](https://github.com/CallMeRyanYT/RyanDPI/releases/download/v3.0.0/RyanDPI-Portable-Windows-3.0.0.zip)).
2. Pilih mode **Global Universal (Disarankan)** saat pertama kali dibuka dan pilih bahasa **`ID`** di bilah atas.
3. Klik **"Pasang & Aktifkan RyanDPI"**, lalu klik **"Jalankan Uji"** untuk memverifikasi koneksi.

### Android (Android 10–16, Tanpa Root)
1. Unduh dan pasang **[RyanDPI-Android-3.0.0.apk](https://github.com/CallMeRyanYT/RyanDPI/releases/download/v3.0.0/RyanDPI-Android-3.0.0.apk)**.
2. Pilih **Global Universal**, ketuk **"Hubungkan & Buka"**, dan izinkan VPN lokal Android *(100% berjalan di perangkat, bukan server VPN!)*.
3. Tambahkan **Quick Settings Tile RyanDPI** agar bisa menyalakan/mematikan bypass dalam 1 ketukan.
